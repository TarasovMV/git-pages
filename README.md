# git-pages

Личное хранилище веб-страниц (HTML-артефактов). Каждая страница — один
самодостаточный HTML-файл, доступный по живому URL через GitHub Pages:
<https://tarasovmv.github.io/git-pages/>

## Структура

- `pages/<ключ>/index.html` — папка-страница, URL `/pages/<ключ>/`
- `pages/<ключ>.html` — файл-страница, URL `/pages/<ключ>` (без расширения)
- `index.html` — галерея; **генерируется**, руками не редактировать:
  `python tools/rebuild_index.py`
- не-HTML файлы в `pages/` — статические ассеты, страницами не являются

## Ключ страницы

1–4 сегмента `[a-z0-9][a-z0-9-]*` через `/`, например `color-picker` или
`shagal-electricity/panel`. При коллизии (есть и папка, и одноимённый
`.html`) папка побеждает.

## Метаданные

Необязательный HTML-комментарий первым блоком в файле страницы:

    <!-- page-meta
    title: Заголовок в галерее
    description: Одно предложение
    -->

Даты создания/обновления берутся из git log по файлу.

## Управление

Операции add / update / delete / list / open выполняет агент ZCode через
пользовательский скилл `git-pages`. История каждой страницы — в git.
